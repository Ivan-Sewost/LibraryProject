\# Библиотечная система



Консольное приложение для управления библиотекой на Python и PostgreSQL.



\## Функции

\- Просмотр всех книг

\- Добавление книг

\- Выдача и возврат книг



\## Установка

1\. Установите PostgreSQL

2\. Создайте базу данных `books`

3\. Установите зависимости: `pip install -r requirements.txt`

4\. Запустите: `python Library.py`
